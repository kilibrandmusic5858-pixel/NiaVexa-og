# NiaVexa

A static website for GitHub Pages. To publish it, create a GitHub repository, upload `index.html` and this README, then enable Pages from the repository's Settings.

## Included
- Black and green responsive social feed design
- Guest entry screen
- Sample community feed and working local interactions
- Photo and video selection, in-browser playback, and original-file download
- Local demo inbox, comments, post actions, search, and navigation

## Important
This is a static front-end website. Guest posts, comments, likes, follows, and sample messages only exist in the current browser session. The sign-in screen does not create accounts. The inbox is not a secure messaging service. Do not enter real passwords or private information. A public social network requires a secure backend, user authentication, database, moderation, and media storage.

## Publish on GitHub Pages
1. Create a new public repository on GitHub (for example, `niavexa`).
2. Upload `index.html` and `README.md` from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will show the published `https://YOUR-USERNAME.github.io/niavexa/` address on the Pages settings screen.
